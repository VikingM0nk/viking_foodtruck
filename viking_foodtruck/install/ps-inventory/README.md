# ps-inventory

ps-inventory uses the same item definitions as QBCore.

1. Add items from [`../qb-core/items.lua`](../qb-core/items.lua) into `qb-core/shared/items.lua` (or your Qbox items file).
2. Copy all PNGs from [`../images/`](../images/) into `ps-inventory/html/images/`.
3. Restart `qb-core` / `qbx_core` and `ps-inventory`.
